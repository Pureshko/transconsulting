# Калькулятор для подсчета транспортных перевозок

## Настройка геокодинга Geoapify

Подсказки адресов и геокодирование введённых вручную точек выполняются через
Geoapify. Создайте API-ключ в панели Geoapify и задайте его до подключения
`js/app.js`:

```html
<script>
  window.GEOAPIFY_API_KEY = "YOUR_GEOAPIFY_API_KEY";
</script>
```

Поиск выполняется по всему миру без ограничения по странам, возвращает результаты
на русском языке и отдаёт приоритет адресам рядом с Казахстаном. Язык можно
переопределить в `index.html`:

```js
window.GEOAPIFY_LANGUAGE = "ru";
```

Поскольку калькулятор является статическим сайтом, ключ Geoapify будет виден в
браузере. Ограничьте его в панели Geoapify разрешёнными HTTP referrers/origins и
не используйте этот ключ для серверных интеграций.
